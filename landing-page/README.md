# $Neurons Landing Page

Institutional one-page website for the $Neurons Proof-of-Knowledge token.

## Vercel deployment

1. Add the `landing-page` directory to the repository root.
2. Import the repository into Vercel.
3. Set **Root Directory** to `landing-page`.
4. Keep **Framework Preset** as Next.js.
5. Deploy. No environment variables are required.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```
